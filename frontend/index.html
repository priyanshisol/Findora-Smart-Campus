How Findora Platform Operates

Comprehensive guide for students and campus safety officers

1. Smart Matching Score Matrix

When a lost or found report is published, Findora executes a multi-factor mathematical similarity algorithm comparing target items across 5 core dimensions:

  • Item Title Match 35% Weight
  • Description Token Jaccard Similarity 25% Weight
  • Category Exact Match 15% Weight
  • GPS Proximity (Haversine Formula) 15% Weight
  • Report Date Gap Proximity 10% Weight
2. Privacy & Verification

Private identifying details provided during found item reporting or claim submission are encrypted and restricted solely to authorized university campus administrators to prevent fraudulent claims.

About Findora Project

Findora was created to streamline lost and found management for university campuses. Built with Node.js, Express, MongoDB, and modern web standards.

Full Stack Architecture

MongoDB primary database, JWT HttpOnly security cookies, Multer drag-and-drop file uploads, Chart.js analytics, HTML5 Geolocation API.
